# Portuguese Bank Marketing – Term Deposit Subscription Prediction

## Project Overview
This project focuses on predicting whether a bank customer will subscribe to a term deposit based on customer information and marketing campaign data.

## Objectives
- Understand customer behavior through Exploratory Data Analysis (EDA).
- Identify important factors influencing term deposit subscriptions.
- Build and evaluate machine learning classification models.
- Support better customer targeting for marketing campaigns.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Feature encoding and scaling
5. Machine learning model building
6. Model comparison and threshold tuning
7. Final model evaluation

## Models Compared
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

## Final Model Results
**Selected Model:** Random Forest  
**Decision Threshold:** 0.30

- Accuracy: 87.64%
- Precision: 45.28%
- Recall: 46.55%
- F1-Score: 45.91%

## Key Learning Outcomes
- Practical experience in data preprocessing and EDA.
- Understanding classification algorithms.
- Handling imbalanced classification data.
- Evaluating machine learning models using multiple metrics.

## Conclusion
The project demonstrates how machine learning can help banks identify customers who are more likely to subscribe to term deposits and improve marketing campaign targeting.
